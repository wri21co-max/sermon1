API 설정

🔐 절대 공유 금지

OpenAI API: 더 높은 수준의 논리·사고 능력으로 설교를 정리하기 위해 사용합니다.
Azure Speech API: 더 자연스럽고 좋은 음성을 사용하기 위해 사용합니다.
사용료: 설교 한 편 기준으로 매우 적은 수준입니다.

API Key는 결제와 연결된 개인 비밀번호입니다. 본인의 키만 입력하고 다른 사람에게 보여주거나 전달하지 마십시오.

키가 저장된 브라우저나 컴퓨터를 다른 사람에게 넘기거나 공동 사용하지 마십시오.

창이 길어지면 안쪽을 스크롤할 수 있습니다.

본인의 OpenAI API 키를 넣으십시오. 아래의 Google Cloud TTS API 키와 구분됩니다. 이 앱의 HTML 파일에는 키를 저장하지 않습니다.

Azure Speech Key와 리전을 넣으면 고음질 한국어 Neural 음성을 사용합니다.

Azure Speech 설정 안내
Speech 리소스의 Key와 Region이 서로 맞아야 합니다. 이번에 만든 리소스는 East US이므로 eastus를 사용하십시오. 예: eastus, koreacentral, eastasia. 리전이 다르면 인증 오류가 납니다.
API 키는 비밀번호와 같습니다. 개인용 컴퓨터에서만 저장하고 다른 사람에게 보내지 마십시오.
